# AuraMart — E-commerce Microservices

Event-driven e-commerce platform with an AI shopping assistant.
Spring Boot microservices · Kafka saga · Redis · PostgreSQL/pgvector · MySQL · MongoDB · React + TypeScript.

Designed for 10,000 RPS — see [docs/SYSTEM_DESIGN.md](docs/SYSTEM_DESIGN.md).

## Structure
- `frontend/` — React + TypeScript + Tailwind web app
- `docs/` — architecture, system design, build guide, ADRs
